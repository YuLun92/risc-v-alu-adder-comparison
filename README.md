# Design and Optimization of a 32-bit ALU for a RISC-V Processor

## Supported Operations

- ADD
- SUB
- AND
- OR
- XOR
- SLT
- SLL
- SRL

## Project Goal

This project investigates the impact of different adder architectures
on the hardware cost and timing characteristics of a 32-bit RISC-V ALU.

Adder architectures to be evaluated:

1. Ripple Carry Adder (RCA)
2. Carry Lookahead Adder (CLA)
3. Carry Select Adder (CSLA)
